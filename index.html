Personal database backup tool

Full database backups saved to the owner's Google Drive.

Alraed Database Backup is a personal Windows backup workflow operated by Mohammed Enad. It creates a full backup of the AlraedDb SQL database, checks the backup, and uploads the completed file to the owner's Google Drive.

How the backup works

  • A Windows task starts the backup daily at 8:00 PM Baghdad time.
  • The database backup is saved locally and checked before upload.
  • rclone uploads the completed backup to a dedicated folder in the owner's Google Drive and checks the transferred file.
  • After a successful verified upload, the latest three backups remain in each location. Failed runs preserve existing backups for recovery.

Why Google Drive access is requested

The owner authorizes Google Drive access so the local backup tool can create backup files, read their metadata for transfer verification, list its own backup files, and delete older backups according to the retention setting.

The workflow uses the drive.file permission, which limits access to files and folders created by or explicitly made available to the app. It does not request Gmail access. This website describes the workflow; it does not accept database uploads or ask for Google passwords.
